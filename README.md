# Steeplechase Past Performances

A handicapping app for American steeplechase racing. Pick the horses entered in a
race and compare their past performances side by side, Daily Racing Form style,
with a comparison sheet and head-to-head meetings.

20,236 horses, 141,033 starts, 1966-2026. Data built 2026-10-27.

- `index.html` - the app
- `data/pp.json.gz` - the past-performance data, gzipped JSON

Rebuilt automatically each week from the steeplechase results database.
